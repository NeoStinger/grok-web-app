# Grok Web

Public website + installable app for chatting with xAI Grok.

**Live site:** https://neostinger.github.io/grok-web-app/

## Use it
1. Get an API key at [console.x.ai](https://console.x.ai)
2. Paste it in Settings (saved only in your browser)
3. Chat with Grok 4 Fast, 4.6, 4.7, and more
4. On phone: Share → Add to Home Screen. On desktop: use the install button in the sidebar

This is an unofficial client. Keys never go into this repo.
